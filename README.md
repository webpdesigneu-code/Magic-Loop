# Magic Loop (HandmadeByAnna)

A bilingual e-commerce showcase for handmade products, built with Next.js 15.

🔗 **Live Site:** [https://magicloop.se](https://magicloop.se)

---

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Run Local Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the site.

## 🛠 Deployment

To deploy updates to the production server:

```bash
./deploy.sh
```
You will be prompted for the VPS user (`root`) and IP (`93.127.214.180`).
